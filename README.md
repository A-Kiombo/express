# Simulador de Transferência Bancária (Mobile)

Projecto simples de simulação de operações bancárias desenvolvido com HTML5, CSS3 e JavaScript puro.

## 📱 Funcionalidades
- Interface otimizada para dispositivos móveis.
- Validação de saldo disponível.
- Atualização do saldo em tempo real.
- Mensagens de feedback dinâmicas.

## 🚀 Como executar
Basta abrir o ficheiro `index.html` em qualquer navegador ou utilizar a extensão **Live Server** no VS Code.
